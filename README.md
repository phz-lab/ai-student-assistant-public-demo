# 学生档案列表 Demo

仅展示学生档案列表。AI 识别录入支持在同一输入框中填写文字、添加课堂板书图片，或使用麦克风实时录音转写；每个学生操作栏提供识别入口，核对字段和修改前后值后更新当前学生档案。

- 所有列表样例均为虚构数据。
- 图片通过浏览器本地 OCR 识别；字段提取使用演示规则，不连接大模型服务。
- 录音转写使用浏览器语音识别，需麦克风权限；部分浏览器会将音频发送到服务端处理，且浏览器支持情况不同。
- 确认更新后的内容保存在当前浏览器的本地存储中。
- 列表字段按钉钉原表及本次确认的角色权限、类型和必填规则提供编辑；规划师和学管师标签页用于模拟对应角色，未指定维护角色的字段暂只读。
- 字段编辑和权限判断是前端 Demo 交互，修改仅保存在当前浏览器；附件仅记录文件名，不连接真实学生系统或后端鉴权。
